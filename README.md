# Bayesian_Probability_Simulation-

# Bayesian Update Simulation via Beta Distribution

A computational statistics application that simulates iterative Bayesian learning. It takes consecutive observational outcomes (coin flips) and recalculates likelihood functions and posterior alpha/beta parameters in real-time.

## Features
**Statistical Logic:** Models recursive adjustments to parameters as new dataset signals are observed.
**Likelihood Optimization:** Computes vector exponent mechanics based on dynamic event frequency tracking.
**Array Processing:** Leverages `numpy` to efficiently parse raw arrays of binary categorical strings.

## Tech Stack
**Python 3**
**SciPy:** Scientific computing package utilized for statistical analysis workflows.
**NumPy:** Vectorization handling for input tracking matrices.
